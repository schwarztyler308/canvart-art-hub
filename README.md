## Overview

CanvArt serves anyone looking for an uncomplicated way to discover visual work online and join a lively creative community. Browsing, publishing, and discovery all live inside a single web experience, so the step from admiring someone else's art to posting your own stays short.

Artists, photographers, and makers who want their output shown next to other community submissions will find it a good match. A gallery-first layout paired with community-oriented discovery makes it useful both for quick browsing sessions and for regular participation.
